# Arquivos
### Kotlin

Os arquivos .kt devem ser nomeados usando PascalCase e seguir o padrão descrito abaixo:

| Asset | Padrão
|---|---
| Activity | `NomeDaTelaActivity.kt`
| Adapter  | `NomeDaFonteAdapter.kt`

### Layout

Os arquivos de layout devem ser nomeados usando snake_case e seguir o padrão descrito abaixo:

| Asset | Padrão
|---|---
| Activity | `activity_nome_da_tela.xml`
| Componente Genérico  | `component_nome_do_componente.xml`

### Drawable

Os arquivos de drawables devem ser nomeados usando snake_case e seguir o padrão descrito abaixo:

| Asset | Padrão
|---|---
| Icone | `ic_nome_do_icone.xml`
